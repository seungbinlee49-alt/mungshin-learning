# 멍신러닝 · Mungshin Learning

**주인을 보면 개가 보일까요?** 200쌍의 보호자–반려견 사진에서 관계를 학습하는 전통 머신러닝 프로젝트입니다.

**[웹 보고서](https://seungbinlee49-alt.github.io/mungshin-learning/)** · [모델·평가 설명](docs/method.md) · [동일 설정 전체 비교](docs/comparison.md) · [특징 제거 실험](docs/ablation.md) · [실험 코드](experiments/)

## 대표 결과

200개 관계, 사람·개 각 3장, 총 1,200장. 관계 단위 5-fold × 3seed, 매 분할 학습160쌍/평가40쌍, 후보10마리입니다. 학습은 대상별3장 특징 평균입니다.

| 평가 입력 | Top-1 | Top-3 | 무작위 기대값 |
|---|---:|---:|---|
| 단일 사진 | **22.22%** | **53.89%** | 10% / 30% |
| 3장 특징 평균 | 26.67% | 61.50% | 10% / 30% |

단일 평가에서는 점수 계산마다 사람1장·개별1장만 사용하며, 고정된 세 cyclic 사진 경로의 지표를 평균합니다. 3장 특징을 평균한 뒤 평가하는 것과 구분합니다.

같은200쌍을 방법 개발에 반복 사용했습니다. 위 수치는 반복 교차검증 결과로, 탐색에 쓰지 않은 새로운 독립 최종 평가 성능은 아닙니다. 관계 예측을 외형적 닮음의 인과 증거나 입양 적합성 확률로 해석하지 않습니다.

## 방법

```text
전체 HOG1764 + 다중 uniform LBP864 + alpha 가중 HSV96
                         + 정렬 눈 LBP20
          → 정규화·결합 → 학습 사진 특징 평균 → L2
          → 사람/개 별도 PCA8 → L2
          → 교차곱64 → 가중 StandardScaler
          → 로지스틱(λ=.01) → 후보 순위
```

PCA·결측 대체·표준화·관계 학습은 해당 학습 fold만 사용합니다. 로지스틱·선형SVM·RBF-SVM·RankSVM을 동일 특징/분할/후보/전체오답 조건으로 비교했습니다.

## 저장소 구성

- `site/`: 설치·빌드 없이 열리는 한국어 연구 보고서, SVG 그래프, 집계 결과 CSV/JSON
- `docs/`: 방법, 고정 비교, 최신 제거 실험, 보조 2지선다 결과
- `experiments/`: 실제 사용한 특징 추출·PCA·관계 학습 코드와 로컬 데이터용 실행기
- `evidence/`: 완료된 실험의 검산 기록과 집계 차이
- `tools/`: 공개 보고서 자료 생성·검사
- `.github/workflows/pages.yml`: 자료 검사 후 GitHub Pages 배포

인물·반려견 원본 사진, 수동 눈 좌표, 이미지 특징 캐시, 관계별 예측 및 학습 모델은 공개하지 않습니다. 공개 집계표는 사진 데이터 없이 확인할 수 있습니다. 전체 모델 재현은 로컬 연구 자료가 필요하며 [실험 안내](experiments/README.md)를 참고하세요. 로컬 시연 앱은 별도 프로젝트이며, 이 정적 웹 보고서에서 서버 추론을 제공하지 않습니다.

## 보고서 로컬 확인

```bash
python tools/check_report.py
python -m http.server 8000 --directory site
```

http://localhost:8000 에서 확인합니다. 그래프와 평가 조건 전환은 `file://` 대신 HTTP로 여는 것이 좋습니다. 표와 원문은 JavaScript 없이도 읽을 수 있습니다.

집계 CSV가 바뀌면 `python tools/assemble_report_data.py`로 웹용JSON을 다시 만듭니다. 모델을 새로 학습하는 명령이 아닙니다.
