# 동일 설정으로 통일한 최종 모델 전체 비교

이 문서는 앞선 ‘오답 19개·내부 설정 선택’ 모델 비교표를 대체한다. 이번에는 모든 분류기·학습량·사진 장수 조건을 하나의 실험 규약으로 통일했다. 모든 수치는 Top-1 / Top-3(%).

## 핵심 해석

- 확정 로지스틱을 유지할 만하다. 160쌍·3장 학습의 단일 평가22.22/53.89%, 3장 평균 평가26.67/61.50%가 그대로 재현됐다.
- 선형 SVM과 RankSVM도 비슷한 수준이다. 3장 학습·단일 평가 RankSVM22.33/54.06%와 로지스틱의 차이는 매우 작다. 3장 평균 평가에서도 RankSVM27.17/60.17%로 Top-1은 약간 높지만 Top-3는 낮아, 분명한 우월성을 보여주는 결과가 아니다.
- 학습 장수가 늘면 모든 지표가 반드시 오르지는 않는다. 로지스틱의 3장 평균 평가에서 2장 학습27.67/58.33%, 3장 학습26.67/61.50%다. Top-1과 Top-3가 다른 방향으로 움직이는 작은 차이를 구분해야 한다.
- 학습 장수만 늘리는 효과는 비교적 작다. 로지스틱 단일 평가의 1→3장 학습은21.06/50.28%→22.22/53.89%다. 반면 3장 학습을 유지하고 평가 입력을1→3장으로 늘리면22.22/53.89%→26.67/61.50%다.
- 같은 평가 대상에서 학습 관계 수 증가가 도움이 됐다. 로지스틱3장 학습의 40→160쌍은 단일 평가17.39/44.70%→22.22/53.89%, 3장 평균 평가18.50/47.89%→26.67/61.50%다. 이는 현재 범위의 학습 곡선이며300쌍 성능 보장은 아니다.

## 공통 고정 설정

- 전체 HOG+다중 반경 LBP+HSV 2,724차원＋기존 정렬 눈 LBP20. 전처리·배율·눈 좌표·사진별 결합 방식 고정.
- 지정한 학습 사진 1/2/3장의 특징 평균 → 사람·개 각각 학습 자료로만 PCA8 → 출력 L2 → 교차곱64.
- 모든 분류기에 **학습 집합의 모든 오답**을 사용. n쌍이면 정답 n개, 오답 n(n−1)개다. 정답·오답 가중치 합은 각각0.5, 전체1이다.
- 같은 가중 StandardScaler를 같은 학습 쌍에 맞춘다. 네 모델의 scaler 통계 일치를 각 경우마다 검사한다.
- Logistic λ=0.01, Linear SVM λ=0.01, RankSVM λ=0.01, RBF-SVM C=1,000·gamma=scale로 사전 고정. RBF는 가중치 합1 단위다. 내부 설정 선택과 바깥 평가 후 설정 변경은 하지 않는다.
- 서로 다른 모델에서 규제 숫자가 같다고 용량이 같다는 뜻은 아니다. 고정 설정에서 분류기 종류를 바꾸는 비교이며, 각 모델을 광범위하게 최적화한 비교는 아니다.
- RankSVM은 같은 보호자의 정답−오답 특징 차이를 학습하는 목적함수 때문에 입력 행 구성이 다르지만, 원본 관계·사용 오답·특징·pair scaler는 동일하다. 절편 없이 대칭 차이 표본을 사용하고 가중치 합1을 유지한다.
- 200개 관계를 독립 세트로 취급, 원래 5-fold×3seed 고정. fold별 평가40쌍, 후보10마리를 모든 조건에서 동일하게 유지.
- 학습 사진은 원래 path0 선택. 단일 사진 평가는 세 cyclic 경로를 평균하고, 3장 평균 평가는 세 장을 평균한 벡터로 한 번 평가한다. 학습1/2/3장 각각 두 평가 조건을 모두 적용한다.
- 실제 학습량40/80/120/160쌍. 작은 학습량은 같은 중첩 순열3개로 반복하며, 모든 모델에서 같은 부분집합을 쓴다. 160쌍은 세 부분집합 반복이 동일하므로 한 번만 학습한다.
- 눈이 보이지 않는 개 사진2장의 눈 벡터는 선택된 유효 **학습 사진** 평균으로 대체한다. 관계·원본 전체 특징은 유지한다.

## 검증과 해석 범위

- 기존 전체 오답·고정 로지스틱의 모든 학습량·사진 수 조건에서 예측을 재현했다. 로지스틱 행은 모델 비교표·사진 장수 표·학습량 표에서 동일한 결과를 사용한다.
- 모든 모델의 학습 쌍 수·정답 수·pair scaler 통계 일치를 검사했다. 작은 학습 집합의 포함 관계와 평가 집합 분리도 확인했다.
- 무작위 기대값은 Top-1 10%, Top-3 30%다.
- 40/80/120/160은 실제 학습 관계 수다. 200쌍 전체 학습 결과나 새로운 독립 데이터셋50/100/150/200개 실험으로 바꾸어 부르면 안 된다.
- `conditional_intervals.csv`, `paired_vs_LR.csv`는 관계200개를 단위로 계산한 조건부 bootstrap 구간이다. 반복 seed·사진 경로를 독립 사람처럼 세지 않는다. 학습모델을 bootstrap마다 재학습하거나 과거 방법 탐색을 보정한 구간은 아니다.
- 같은200쌍을 방법 개발에 반복 사용했다. 평가 누출 방지와 별개로, 새로운 독립 최종 검증이 완료된 것은 아니다. 작은 모델 간 차이를 확정 우위로 해석하지 않는다.
- 같은 분할·사진·모델 설정·난수를 고정하므로 실행할 때마다 점수가 임의로 바뀌는 비교가 아니다.

## 결과 파일

`runs/unified_final_comparison_v1/summary.csv`에 4모델×4학습량×3학습사진수×2평가조건=96행이 있다. `predictions.csv`는 후보·관계별 결과, `case_checks.csv`와 `checks.json`은 공통 조건 검증, `protocol.json`은 사전 고정 설정이다.

기존 로지스틱 학습 결과는 설정을 변경하지 않고 검산 후 재사용했다. 같은 모델의 전체 실험을 새로 학습한 것처럼 부풀려 집계하지 않는다. 다른 세 모델은 동일 전체 오답 조건으로 학습했다. 모든 실행은 완료됐으며 PPT는 변경하지 않았다.
