# 최종 로지스틱 특징 제거 실험

전체 특징＋눈 LBP → 종별 PCA8 → 교차곱64 → 고정 로지스틱의 특징을 하나씩 제거했다. 학습3장·전체 오답·λ=0.01·같은15분할/후보를 유지하고 PCA·scaler·분류기를 다시 학습했다. 평가는 단일 사진만 사용한다. 숫자는 Top-1 / Top-3(%).

| 구성 | 단일 사진 평가 |
|---|---:|
| 전체 특징 사용 | 22.22 / 53.89 |
| HOG 제거 | 22.50 / 52.00 |
| 전체 LBP 제거 | 20.11 / 49.50 |
| HSV 제거 | 16.44 / 42.33 |
| 눈 LBP 제거 | 19.78 / 49.11 |

## 제거 시 하락 폭

양수는 해당 특징을 제거했을 때 성능이 낮아졌다는 뜻이다. 단위는 %p. 대괄호는 관계 단위 대응 bootstrap의 조건부95% 구간이다.

| 제거 특징 | 평가 | Top-1 하락 [구간] | Top-3 하락 [구간] |
|---|---|---:|---:|
| HOG 제거 | 단일 사진 | -0.28 [-2.56, +2.06] | +1.89 [-0.78, +4.50] |
| 전체 LBP 제거 | 단일 사진 | +2.11 [+0.00, +4.17] | +4.39 [+1.50, +7.22] |
| HSV 제거 | 단일 사진 | +5.78 [+2.11, +9.44] | +11.56 [+6.83, +16.33] |
| 눈 LBP 제거 | 단일 사진 | +2.44 [+0.39, +4.56] | +4.78 [+2.11, +7.56] |

## 해석 기준

- 이 실험은 최종 눈 결합 모델에서 수행했다. 과거 눈 추가 전의 HOG/LBP/HSV 제거 표와 다르다.
- 제거 후 고정8차원으로 PCA를 다시 학습하므로, 없는 특징의 대체 가능성까지 포함한 재학습 성능이다. 전체 모델의 특정 가중치만0으로 바꾸는 시험이 아니다.
- 제거 후 남은 전체 특징은 기존 정책대로 L2 정규화한다. 나머지 특징의 상대 비중과 PCA 축도 바뀐다. 순수한 인과 기여율이나 외형·생물학적 원인을 측정한 결과는 아니다.
- 구간에0이 포함되면 하락 방향의 평균이 있더라도 뚜렷한 개선 근거라고 단정하지 않는다. 네 특징 모두 성능을 올렸다고 결과와 무관하게 주장하지 않는다.
- 같은200관계를 개발에 반복 사용한 조건부 비교다. 새 독립 검증이나 과거 모든 탐색을 보정한 유의성 검정은 아니다.
- 전체 모델은15개 분할 모두 기존 최종 로지스틱 예측을 재현했다. 평가 데이터 변조에도 학습 전처리가 변하지 않는지 검사했다.

## 발표용 해석

색상(HSV)·전체 질감(LBP)·눈 주변 질감(LBP)은 제거 시 Top-3가 각각11.56,4.39,4.78%p 낮아져 현재 모델에서 유용한 정보를 제공하는 근거가 있다. 전체 LBP의 Top-1 하락 구간 하한은0부근이므로 Top-3 근거와 구분한다.

HOG 제거 시 Top-1은0.28%p 높고 Top-3는1.89%p 낮았다. 두 차이 구간 모두0을 포함한다. 현재 최종 모델에서 HOG의 추가 이득은 명확하지 않으며, 다른 특징과의 중복 가능성이 있다. 과거 눈 추가 전 제거 실험의 HOG 효과를 최종 모델에도 그대로 적용하지 않는다.

> 최종 로지스틱에서 특징을 하나씩 제거해 재학습한 결과, HSV·전체 LBP·눈 주변 LBP는 제거 시 상위 후보 검색 성능이 낮아졌습니다. 반면 HOG는 추가 효과가 명확하지 않아, 현재 결과만으로 모든 특징이 반드시 필요하다고 결론 내리지는 않았습니다.
