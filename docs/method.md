# 모델과 평가 규약

## 질문

사진에서 추출한 정보로 실제 보호자–개 관계를 무작위보다 잘 순위화할 수 있는지 평가합니다. 외형적 닮음, 성격, 선호의 인과관계나 입양 적합성은 측정하지 않습니다.

## 데이터와 분할

- 200개 관계 × 사람3장+개3장 = 1,200장. 관계를 독립 단위로 취급합니다.
- 같은 관계의 모든 사진은 함께 분할합니다. 고정5-fold × seed20261101/20261102/20261103, 매회160학습/40평가입니다.
- 각 평가 관계의 실제 개1+다른 평가 개9, 총10후보를 고정합니다.
- 같은200관계를 개발에 반복 사용했으므로 독립 최종 테스트는 아닙니다. 동일인·출처 중복이 전혀 없음을 별도 탐지로 검증한 것도 아닙니다.

## 특징

| 분기 | 설정 | 차원 |
|---|---|---:|
| 전체 HOG | 흰 배경 합성·흑백64×64, 방향9, 셀8×8, 블록2×2, L2-Hys | 1,764 |
| 전체 다중 uniform LBP | (P,R)=(8,1),(16,2),(24,3), 공간4×4 | 864 |
| HSV | 128×128, 채널당32bin, alpha 가중 | 96 |
| 눈 uniform LBP | 두 눈을96×32에 정렬, 각32×24, P8/R1, 눈별10bin pooling | 20 |

전체 분기2724차원과 눈20차원을 각각 정규화 후 결합/L2. 선택한 학습 사진1·2·3장의 특징을 평균/L2. 눈이 보이지 않는 개 사진2장의 눈 특징만 선택된 유효 **학습 사진**의 역할별 평균으로 대체합니다. 관계와 전체 특징은 유지합니다.

## 압축과 관계 학습

1. 사람용·개용 PCA를 각각 학습합니다. n_components=8, svd_solver=full, whiten=False.
2. 변환 출력은 L2 정규화합니다. 8차원 사람과8차원 개의 모든 교차곱을 평탄화해64차원 관계 표현을 만듭니다.
3. 학습 관계의 실제 n쌍을 양성, 다른 n(n−1)쌍을 음성으로 모두 사용합니다.
4. 양성 전체0.5, 음성 전체0.5의 sample_weight, 총합1. 동일 학습쌍으로 가중 StandardScaler를 맞춥니다.
5. Logistic L2 λ=.01(C100), lbfgs, max_iter2000, tol1e-8. 선형SVM·RankSVM λ=.01, RBF-SVM C1000/gamma=scale. 내부 설정 선택은 하지 않습니다.

다른 분류기의 같은 규제 숫자가 같은 용량을 의미하지는 않습니다. RankSVM은 같은 보호자의 정답−오답 차이로 학습하며, 원본 쌍과 pair scaler는 동일합니다.

## 평가

단일 사진 평가는 점수마다 사람1·개별1장을 사용합니다. 세 cyclic 경로에서 계산한 지표를 평균합니다. 모든3×3 사진 조합을 전수 평가하지 않습니다. 3장 평균 평가는 사진 벡터를 평균한 뒤 한 번 평가합니다.

주 결과는 학습3장·단일 평가 Top-1 22.22/Top-3 53.89%. 3장 평균 평가는26.67/61.50%. 각 수치는 분리해 보고합니다.

40/80/120/160은 동일 평가집합에서 실제로 쓰는 학습 관계 수입니다. 작은 집합은 같은 중첩 순열3개로 반복하고160은 동일 반복을 한 번만 학습합니다.

## 선정 근거와 해석 범위

전체PCA8의19.78/49.11보다 전체+눈PCA8의22.22/53.89가 유망했습니다. 전체+눈PCA4는19.28/47.67, 전체4+눈4는19.39/49.89였습니다. 해당 자료에서의 탐색 결과이며 보편적인 최적 설계의 증명은 아닙니다.

최종 단일 평가 제거 실험에서 HSV·전체LBP·눈LBP 제거 시 Top-3가 낮아졌습니다. HOG는 추가 이득이 명확하지 않습니다. 수집·누끼·촬영 조건이 특징에 반영될 수 있으므로 생물학적 닮음이나 성격으로 확장 해석하지 않습니다.

현재 시연 앱의 자동 전처리는 YuNet/U2NetP이고, 연구 평가의 수동 전처리와 다릅니다. 시연20후보의 성능을 연구10후보 결과로 표시하지 않습니다.
