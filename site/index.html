01 / QUESTION

“개는 주인을 닮는다”를
사진 기반의 예측 문제로.

익숙한 말에서 출발했지만, 우리가 직접 검증한 질문은 조금 더 좁습니다. 사진에서 계산한 정보만으로 실제 보호자–반려견 관계를 무작위보다 잘 찾아낼 수 있을까요? 한 보호자의 사진과 개 후보 10마리를 주고, 실제 반려견이 얼마나 높은 순위에 오는지 측정했습니다.

사람이 자신과 닮은 개를 선택한다는 인과 가설을 검증하거나, 사람과 개의 “닮음”을 직접 측정한 실험은 아닙니다. 실제 관계를 맞히는 예측 성능과 그 관계가 만들어진 이유는 구분했습니다.

핵심 관찰

학습에 사용하지 않은 관계를 평가했을 때, 단일 사진 입력의 Top-1은 22.22%, Top-3는 53.89%였습니다. 후보 10마리의 무작위 기대값은 각각 10%, 30%입니다.

같은 200쌍으로 방법을 개발하며 얻은 반복 교차검증 결과입니다. 새로운 독립 최종 평가의 성능은 아닙니다.

‘단일 사진 평가’는 무엇을 뜻하나요?

한 번의 점수 계산에는 사람 1장과 개 후보별 1장만 들어갑니다. 사진 선택에 따른 변동을 줄이기 위해 고정된 세 cyclic 경로에서 각각 평가하고 지표를 평균했습니다. 특징을 3장 평균한 후 점수를 내는 ‘3장 평균 평가’와는 다른 조건입니다. 모든 3×3 사진 조합을 전부 평가한 것도 아닙니다.

반복 seed와 사진 경로를 새로운 독립 참가자처럼 세지 않았습니다. 학습량 비교의 40·80·120·160은 실제 학습 관계 수이며, 전체 데이터셋 크기가 아닙니다.

사진을 수치로,

◉↔◉

두 눈 위치와 간격을 맞춘 뒤 각 32×24 영역을 추출합니다. 눈별 10개 패턴 분포를 사용합니다.

위 도형은 계산법을 설명하는 도식입니다. 실제 추출 특징의 시각화가 아닙니다.

특징 계산과 정규화의 정확한 설정

HOG: 흰 배경 합성 후 흑백 64×64, 방향 9개, 셀 8×8, 블록 2×2, L2-Hys. 전체 LBP: uniform (P,R)=(8,1),(16,2),(24,3), 공간 4×4. HSV: 128×128에서 채널별 32bin, alpha 가중.

눈: 유사변환으로 두 눈을 96×32 영상의 (24,16), (72,16)에 맞추고 각각 32×24 패치를 얻습니다. uniform LBP(P=8,R=1)의 2×2 구역 중간 표현을 눈별로 pooling해 20차원으로 만듭니다. 안 보이는 눈을 복원하는 기술은 아닙니다.

전체 분기 내부의 정규화·결합을 거친 2,724차원과 L2 정규화한 눈 20차원을 이어 다시 L2 정규화합니다. 선택한 사진 벡터를 평균한 뒤 L2 정규화합니다. HOG/LBP는 흰 배경 합성 이미지를 처리하므로 누끼 경계의 영향이 완전히 사라지지는 않습니다.

사람의 축과 개의 축을 따로 학습합니다

↓

↓

사람과 개의 픽셀 특징은 같은 의미의 좌표가 아닐 수 있습니다. 각각의 변동을 8차원으로 요약한 뒤, 같은 축끼리 빼는 대신 모든 성분의 교차곱을 만듭니다. 어떤 사람 특징과 어떤 개 특징이 함께 나타나는지 관계 라벨로 학습합니다.

zij = hi · dji, j = 1, …, 8

실제 관계는 1, 다른 조합은 0입니다. n쌍의 정답 n개와 오답 n(n−1)개를 모두 사용하며, 정답 전체와 오답 전체의 가중치를 각각 0.5로 맞췄습니다. 로지스틱은 L2 규제 λ=0.01(C=100)로 고정했습니다. 점수는 후보를 정렬하는 데 사용하며 입양 적합성의 확률로 해석하지 않습니다.

이 제거 실험이 말해주지 않는 것

제거 후 남은 특징의 정규화와 PCA 축도 달라집니다. 특정 가중치를 0으로 만드는 실험이나 순수한 인과 기여율 측정이 아닙니다. 관계 단위 대응 bootstrap 구간은 기존 모델·예측에 조건부이며, 매 반복에서 재학습하거나 과거 탐색을 보정한 구간은 아닙니다. 전체 LBP 제거의 Top-1 하락 구간 하한은 0 부근이므로 Top-3 근거와 구분합니다.

07 / INTERPRETATION

맞혔다고 해서,
이유까지 알아낸 것은 아닙니다.

01

현재 자료에서 관계 예측 신호를 관찰했습니다.

무작위 기대값보다 높은 결과를 얻었습니다. 이는 외형의 닮음, 선호, 촬영 조건의 영향을 구분한 인과 결론은 아닙니다.

02

평가 누출 방지와 반복 탐색의 편향은 다릅니다.

관계 분할과 학습 자료 전용 전처리를 지켰지만, 같은 200쌍을 개발에 반복 사용했습니다. 탐색에 쓰지 않은 독립 평가나 촬영 출처 단위 검증이 필요합니다.

03

색상이 유용해도 촬영 단서일 수 있습니다.

04

추천 순위는 입양 적합성이나 성격이 아닙니다.

행동·생활 환경·돌봄 조건을 학습하지 않았습니다. 사진 기반 탐색의 가능성을 보여주는 시연으로 범위를 제한했습니다.

보조 실험: 2지선다에서는?

같은 모델을 재학습하지 않고 실제 개와 다른 개 한 마리를 비교하면 평균 정답률은 67.66%였습니다(무작위 50%). 각 평가 관계마다 오답 39마리를 하나씩 비교한 평균이지, 한 번에 40마리 중 고른 정답률은 아닙니다. 문제 난도가 달라 10후보 성능과 직접적인 향상 비교를 하지 않습니다.

08 / DEMO & REPRODUCTION

연구 결과를,
사진 한 장의 경험으로.

입력 사진의 얼굴 영역·배경·눈 위치를 자동으로 정리한 뒤, 기존 특징 추출과 로지스틱 모델로 등록된 반려견의 순위를 계산하는 로컬 시연 앱도 만들었습니다.

실제 사진 대신 도식으로 재구성한 화면입니다. 이 페이지에서 사진 업로드나 모델 추론이 실행되지는 않습니다.

시연은 학습에 사용하지 않은 20마리가 후보입니다. 평가의 10후보와 시연의 20후보는 다른 조건입니다. 자동 전처리에는 사전학습 YuNet·U2NetP를 사용하지만, 보고한 실험은 수동 누끼·눈 좌표와 전통 특징을 사용했습니다. 자동 전처리 시연에 기존 평가 수치를 그대로 적용하지 않습니다.

집계 결과와 보고서는 사진 데이터 없이 확인할 수 있습니다. 모델 재학습은 별도로 제공받은 로컬 연구 자료가 필요합니다.

원본 인물·반려견 사진, 눈 좌표, 이미지 특징 캐시는 공개하지 않았습니다. 공개 파일은 집계 결과, 고정 규약, 방법 설명과 재현 코드입니다.
